# همسان

**English:** [README.md](README.md) · **فارسی**

یک برنامهٔ وب محلی که پوشه‌ای از کامپیوتر شما را مرور می‌کند و فایل‌های تکراری را در تمام زیرپوشه‌ها پیدا می‌کند. رابط کاربری فارسی و راست‌به‌چپ است.

هیچ فایلی به اینترنت یا سرور بیرونی فرستاده نمی‌شود. سرور فقط روی `127.0.0.1` گوش می‌دهد و تنها پوشه‌ای را که انتخاب می‌کنید می‌خواند.

## چه کاری انجام می‌دهد

- پوشه را مستقیماً از رابط کاربری انتخاب می‌کنید؛ بدون آپلود و بدون محدودیت پنجرهٔ انتخاب فایل.
- فقط تصویر، ویدیو، صدا و سند نمایش داده می‌شود و بقیهٔ فایل‌ها نادیده گرفته می‌شوند.
- هر فایل با نام، ابعاد یا مدت‌زمان، حجم، نوع، وضعیت تکرار و محل نسخه‌های تکراری فهرست می‌شود.
- دو فایل وقتی تکراری محسوب می‌شوند که **پسوند یکسان و حجم بایتی دقیقاً یکسان** داشته باشند.
- پیمایش پوشه‌ها به شکل لیستی و شبیه فایل‌منیجر، همراه با مسیر (breadcrumb)، بازگشت و جست‌وجو.
- جست‌وجو در پوشهٔ جاری یا در کل درخت اسکن‌شده، با یکسان‌سازی حروف فارسی و عربی.
- پیش‌نمایش تصویر، ویدیو، صدا، PDF و فایل متنی در همان صفحه، با پشتیبانی از range request برای جابه‌جایی در ویدیو و صدا و دکمهٔ دانلود.
- نمایش ابعاد تصویر به‌صورت درخواستی و خواندن ابعاد و مدت‌زمان ویدیو و صدا در مرورگر.
- فیلتر «فقط تکراری‌ها»، گروه‌بندی تکراری‌ها بر اساس دسته و محاسبهٔ فضای قابل آزادسازی.

## تنها خواندن؛ بدون هیچ تغییری در فایل‌ها

این برنامه عمداً **فقط‌خواندنی** است:

- هیچ فایلی حذف، جابه‌جا، تغییر نام، کوتاه یا بازنویسی نمی‌شود.
- فایل‌ها فقط با `stat`، `readdir`، `realpath`، `open(..., 'r')` و ارسال جریان خوانده می‌شوند.
- برنامه هیچ API یا کدی برای نوشتن، حذف یا تغییر Permission ندارد.
- فایل‌های تکراری فقط **گزارش** می‌شوند و پاک‌سازی به‌عهدهٔ خود شماست.

## پیش‌نیازها

- Node.js نسخهٔ ۲۰ یا جدیدتر (با Node 24 آزمایش شده است).
- بدون پایگاه داده، بدون Docker و بدون مرحلهٔ build.

## اجرای محلی

```bash
npm install
npm start
```

سپس <http://127.0.0.1:4870> را باز کنید.

برای توسعه با راه‌اندازی خودکار پس از تغییر کد:

```bash
npm run dev
```

## دسترسی از موبایل در شبکهٔ خانگی

دستور `npm start` فقط روی `127.0.0.1` گوش می‌دهد و تنها همین کامپیوتر می‌تواند آن را باز کند. برای استفاده از موبایل یا تبلت روی همان Wi-Fi:

1. برنامه را در حالت شبکه و محدود به پوشه‌ای که می‌خواهید به اشتراک بگذارید اجرا کنید:

   ```bash
   ALLOWED_ROOTS="$HOME/Pictures" npm run start:lan
   ```

   اگر `ALLOWED_ROOTS` خالی باشد، هر پوشه‌ای که فرایند بتواند بخواند از طریق شبکه قابل مرور می‌شود.

2. آدرس شبکهٔ این کامپیوتر را با `hostname -I` پیدا کنید و روی موبایل `http://<computer-ip>:4870` را باز کنید. سرور نیز آدرس شبکه را هنگام راه‌اندازی چاپ می‌کند.

3. اگر صفحه باز نشد، پورت را در فایروال مجاز کنید:

   ```bash
   sudo ufw allow 4870/tcp
   ```

   پس از پایان کار قاعده را حذف کنید: `sudo ufw delete allow 4870/tcp`.

برنامه همچنان فقط‌خواندنی است، اما تا وقتی در حال اجراست هر کسی روی Wi-Fi شما می‌تواند فایل‌های داخل پوشهٔ مجاز را مرور و دانلود کند. این پورت را روی روتر Forward نکنید و در اینترنت در دسترس قرار ندهید.

## نحوهٔ استفاده

1. یک مسیر مطلق وارد کنید یا روی **مرور** بزنید و پوشه را انتخاب کنید.
2. روی **بررسی این پوشه** بزنید و تا پایان اسکن صبر کنید.
3. پوشه‌ها و فایل‌ها را مرور کنید، به تب **فایل‌های تکراری** بروید یا در همهٔ پوشه‌ها جست‌وجو کنید.
4. برای پیش‌نمایش روی فایل کلیک کنید یا با دکمهٔ تکراری‌ها همهٔ نسخه‌ها را ببینید و به پوشهٔ هرکدام بروید.

## تنظیمات

| متغیر | مقدار پیش‌فرض | کاربرد |
| --- | --- | --- |
| `PORT` | `4870` | پورت HTTP |
| `HOST` | `127.0.0.1` | آدرس اتصال؛ برای استفادهٔ محلی روی loopback بماند |
| `ALLOWED_ROOTS` | *(خالی)* | فهرست پوشه‌های مجاز، جداشده با کاما. خالی یعنی هر مسیری که فرایند بتواند بخواند؛ در حالت شبکه همیشه آن را تنظیم کنید |

نمونه:

```bash
PORT=5000 npm start
```

## Docker (اختیاری)

مخزن یک Dockerfile و فایل Compose دارد، اما برای اجرای محلی به Docker نیازی نیست. کانتینر همان برنامهٔ محلی را اجرا می‌کند؛ پوشهٔ میزبان به‌صورت فقط‌خواندنی روی `/data` سوار می‌شود و تنها مسیر قابل مرور داخل کانتینر است.

```bash
MEDIA_PATH=/absolute/path/to/your/folder docker compose up --build
```

سپس <http://127.0.0.1:4870> را باز کنید. پورت در Compose به `127.0.0.1` بسته شده است و در شبکهٔ شما در دسترس نیست.

## منطق تشخیص تکراری

فایل‌ها بر اساس پسوند حروف‌کوچک‌شده و حجم بایتی دقیق گروه‌بندی می‌شوند. هر پسوند به یکی از چهار دستهٔ تصویر، ویدیو، صدا یا سند نگاشت می‌شود. گروهی گزارش می‌شود که دست‌کم دو فایل داشته باشد. این روش یک بررسی سریع فراداده است، نه هش محتوا؛ بنابراین دو فایل متفاوت با پسوند و حجم یکسان هم کنار هم گزارش می‌شوند.

## نکته‌ها و محدودیت‌ها

- فهرست اسکن‌شده در حافظه نگه داشته می‌شود؛ با راه‌اندازی دوبارهٔ سرور باید دوباره اسکن کنید.
- برنامه هیچ فایلی را حذف نمی‌کند و فقط تکراری‌ها را گزارش می‌دهد.
- فقط فایل‌های معمولی ایندکس می‌شوند. پیوندهای نمادین (symlink) و پوشه‌های سیستمی و زائد مانند `node_modules`، `.git`، `.Trash` و `$RECYCLE.BIN` نادیده گرفته می‌شوند.
- ابعاد و مدت‌زمان ویدیو و صدا به توانایی رمزگشایی مرورگر بستگی دارد.

public/            رابط کاربری فارسی و راست‌به‌چپ (بدون build)
